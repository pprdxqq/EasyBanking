# EasyBanking

A mobile-first banking-style progressive web app prototype, designed to feel at home on iPhone.

## Current prototype
- Responsive app shell with bottom navigation
- Dashboard, demo balance, recent activity, card preview and spending insights
- Dark visual theme and balance visibility toggle
- PWA manifest, service worker and app icon for installation
- Fictional demo data only — no real accounts, deposits, transfers or card payments

## GitHub Pages
Publish from **Settings → Pages → Deploy from a branch → main → / (root)**.

Once deployed, open the Pages URL in Safari on iPhone, tap **Share → Add to Home Screen**, and launch EasyBanking from the Home Screen.

## Important
This is a UI prototype, not a bank or payment service. Do not enter real banking credentials or sensitive financial information.
